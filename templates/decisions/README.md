# 技术决策索引

本目录记录项目的重要技术决策（ADR），避免重复讨论。Architect 负责写入；Coder 和审查者只读，不同意时通过技术异议提出。ADR 是证据文档，其中的链接不作为规范路由。

## 何时写

- 技术选型；模块边界与职责划分；对外接口或数据结构。
- 放弃一个将来可能被重新提出的方案。
- 高风险区域不变量的实现方式。

局部实现细节不写 ADR。

## 规则

- 文件名 `NNNN-主题.md`，序号递增、不复用，按 [ADR 模板](_template.md) 填写，并登记到下方列表。
- 状态取值：提议、已采纳、已废弃、已被 NNNN 替代。已采纳的 ADR 不改结论；决策变化时写新的 ADR，并更新旧 ADR 的状态。
- 影响对外契约或高风险区域的决策须经用户确认，在 ADR 中注明确认来源和日期。
- ADR 只写决策和理由，不写任务进度；任务记录和任务契约通过链接引用 ADR。

## 读取规则

只读与当前任务相关的 ADR，按下方列表查找，不默认加载整个目录。
