# 任务主题

## 授权与范围

- 来源与日期：用户指令原文或摘录，日期。
- 适用范围与边界：本次允许做什么、不做什么。
- 有效状态：有效 / 已结束 / 已被替代（写明替代来源）。
- 允许的行为变化：需求明确允许改变的既有行为；没有则写“无”。
