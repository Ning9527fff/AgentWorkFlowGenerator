# 任务记录索引

本目录保存任务过程产物。通用推进门禁和授权规则以项目入口为准；这里的记录不构成新的通用授权。本目录不计入审查快照。

## 记录规则

- 实现者在需求确认后、开始实现前建立记录：每个任务一个文件，文件名使用 `YYYY-MM-DD-任务主题.md`，按 [记录模板](_template.md) 的小节填写，并在下方列表登记一行。列表只用于查找，状态以记录文件为准。持续的任务在同一文件中维护当前状态，并追加带日期的变更，同一事实不在多处维护。
- 必须保留的产物：任务拆分与规划、用户授权、阶段进度、交接内容、审查问题台账与结论、用户验收状态。
- 授权记录注明来源（用户指令原文或必要摘录）、日期、适用范围和有效状态。来源不明时明确标注，不推测用户已批准；授权结束或被替代时标明，不把历史授权用于新任务。
- 状态取值：未开始、进行中、自检完成、独立审查通过、待用户 review、用户验收通过。
- 技术契约、测试数据和验证产物留在各自的目录，记录中用链接引用，不复制原始敏感数据。

## 读取规则

只在建立或核对当前任务的规划、授权、进度或交接时读取对应文件，不默认加载整个目录或历史记录。
