tag: decide_by_agent

## 授权与范围

- 来源与日期：用户指令原文，日期。
- 适用范围：包括哪些阶段和任务；是否包括细分任务（默认不包括，包括时引用用户原文）。
- 有效状态：有效，到用户完成统一 review 为止 / 已结束 / 已被替代（写明替代来源）。

## 本授权替代的门禁

- 替代项目入口“拆分任务的推进门禁”中适用范围内的用户 review 节点：每份契约完成独立审查后标为“独立审查通过（待统一 review）”，直接推进下一份。
- 不改变的内容：自主推进专题“不变的约束”一节的全部内容；另有：

## Git

- 分支：分支名，从哪个提交切出。
- 提交授权：用户是否明确允许每份契约审查通过后本地提交一次（引用用户原文）；没有明确允许时写“不提交”。
- 不推送，不强制推送，不改写历史。

## 额外的停止条件

自主推进专题的停止条件之外，用户另外要求停下的情况；没有写“无”。
